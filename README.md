# usb-backup.sh

USB / 移动硬盘备份助手 —— 纯 Bash 编写的交互式备份工具。支持完整镜像备份和增量快照备份（硬链接去重），自动检测 U 盘挂载点，彩色中文交互界面。

## 特性

- **完整备份**：`rsync --delete` 将 U 盘内容镜像同步到电脑目录
- **增量快照备份**：基于 `--link-dest` 生成带时间戳的快照，硬链接去重，只占用变化部分的磁盘空间
- **查看历史**：列出所有快照、标记 latest、显示各快照大小
- **删除快照**：交互式清理旧的增量备份
- **自动检测**：扫描 `/media/$USER/*` 与 `/mnt/*` 下的挂载点，也可手动输入路径
- **记忆上次记录**：记住上次使用的 U 盘和目标目录，随时一键复用
- **彩色终端界面**：无需任何图形界面，终端即点即用

## 依赖

- `bash`（4.x+）
- `rsync`
- `findmnt`、`lsblk`（util-linux）
- `xdg-user-dir`（可选，用于解析桌面/文档目录，缺失时自动回退到 `$HOME/Desktop`、`$HOME/Documents`）

## 用法

```bash
chmod +x usb-backup.sh
bash usb-backup.sh        # 或者 ./usb-backup.sh
```

启动后进入主菜单：

```
  1. 完整备份   把 U 盘当前内容同步到电脑
  2. 增量备份   生成快照，只保存变化部分
  3. 查看历史   看现有快照和 latest
  4. 删除快照   清理旧备份
  0. 退出
```

选择备份模式后，按提示选择 U 盘来源、目标目录，确认后即可开始。

## 路径说明

脚本默认使用以下路径（可用环境变量覆盖）：

| 环境变量 | 作用 | 默认值 |
| --- | --- | --- |
| `USB_BACKUP_CONFIG` | 配置保存路径 | `$HOME/.usb-backup.cfg` |
| `USB_BACKUP_LOG_DIR` | 日志目录 | `$HOME/.usb-backup-logs` |
| `USB_BACKUP_DEFAULT_ROOT` | 默认备份根目录 | `$HOME/Backups` |

例如：

```bash
USB_BACKUP_DEFAULT_ROOT="/mnt/big-disk/backup" bash usb-backup.sh
```

日志文件位于日志目录下，完整备份为 `full_<时间戳>.log`，增量备份为 `incr_<时间戳>.log`。启动界面和确认页都会显示本次日志路径。

## 增量备份原理

增量备份不重复复制文件。它会为每次备份创建带时间戳的快照目录，并把新快照 `--link-dest` 到上一次快照——未变化的文件通过硬链接复用，几乎不占额外空间；只有真正变化或新增的文件才写入磁盘。配合 `--delete`，快照始终反映源目录的最新状态。最新的快照会软链接为 `<目标目录>/latest`，方便取用。

## 注意事项 / 安全提示

- **完整备份使用 `--delete`**，目标目录会被同步到与源一致——目标目录里多余的文件会被删除。运行前请确认目标目录无误，避免误删。
- 增量备份的每个快照也是镜像语义（含 `--delete`），删除快照前请确认不再需要。
- 默认排除 `.cache`、`.Trash*`、`lost+found`。
- 日志与配置都写入 `$HOME` 下，不会污染源 U 盘。
